# README

## SuperApp

### Описание

SuperApp — это веб-приложение на Django, содержащее в себе несколько утилит. На данный момент присутствует утилита для отслеживания курсов валют Центрального Банка России за исторический период с построением интерактивных графиков.

### UI-фреймворк
**Django + HTML-шаблоны** с интеграцией **Plotly** для графиков.

### Технологии

- Python 3.12
- Django
- Zeep (SOAP-клиент для API ЦБ РФ)
- Plotly (интерактивные графики)

### Установка и запуск

```bash
# Клонирование репозитория
git clone <repo-url>

cd SuperApp
# Создание виртуального окружения
python -m venv venv
source venv\Scripts\activate # Linux venv/bin/activate 

# Установка зависимостей
pip install -r requirements.txt

cd super_app

# Миграции БД
python manage.py migrate

# Запуск сервера
python manage.py runserver
```

### Использование утилиты

1. Перейдите на главную страницу
2. Укажите период (даты "от" и "до")
3. Выберите одну или несколько валют из списка
4. Нажмите "Получить данные за период" - отобразится интерактивный график курса
